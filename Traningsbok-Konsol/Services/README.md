# Services

Interface som menyn anropar, och klasser som ni bygger.

- `IWorkoutRepository` och `InMemoryWorkoutRepository`: låtsasdatabasen. Ersätt den med er egen databasklass.
- `TrainingTypeService`, `GoalNotifier`, `StatisticsService` och `WorkoutFormatter`: visar demodata, räknar fel med flit eller kastar `NotImplementedException` tills ni byggt dem.
